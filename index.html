Cópia de segurança

Exporte um ficheiro JSON e guarde-o no Google Drive, email ou noutro local seguro. Para recuperar dados, importe esse ficheiro nesta aplicação.

A aplicação guarda os dados no armazenamento do navegador deste dispositivo. Se apagar os dados do site, poderá perder os orçamentos. Faça cópias de segurança regularmente.
