Cópia de segurança e recuperação

Exporte os orçamentos, serviços e definições para um ficheiro JSON. Guarde-o noutro local seguro. Para restaurar, importe uma cópia anterior.

⚠️ Os dados ficam neste navegador e dispositivo. Não há sincronização automática com outros telemóveis. Faça uma cópia antes de limpar os dados do site, trocar de navegador ou de dispositivo.

Instalar no Samsung

Depois de publicar no GitHub Pages, abra o endereço no Chrome, toque em ⋮ e escolha “Instalar aplicação” ou “Adicionar ao ecrã principal”.

A publicação no GitHub e o teste num navegador real são passos separados; criar este pacote não publica automaticamente a aplicação.
